# imperia — 世界史の版図を現代地図に重ねて見るサイト 設計書

日付: 2026-08-23

## 目的

歴史書の固有名詞を地理感覚に結びつける。「この政体は今のどの国か」が、地図を回さなくても常に目に入る状態を作る。
紀元前3000年（メソポタミア・エジプトに最初の国家が現れる）から2010年までの世界全体を、年代断面の切替で追う。

対象はローマに限らない。1断面＝その年代の世界全体であり、同時代の全政体が並ぶ。帝国単位のデータ構造は持たない。

## 非目標

- 地球儀表示
- バックエンド / ログイン / 収益化
- 都市・街道レベルの粒度（OpenHistoricalMap の領分）
- 国境の「正確さ」の追求。元データ作者の但し書きどおり、古代の境界は曖昧なものとして表現する

## データ

### 版図（主データ）
- 出典: aourednik/historical-basemaps (GPL-3.0) の `geojson/world_*.geojson`
- 採用断面: BC3000 〜 2010 の **48断面**
  bc3000, bc2000, bc1500, bc1000, bc700, bc500, bc400, bc323, bc300, bc200, bc100, bc1,
  100, 200, …, 1000 (100年刻み), 1100, 1200, 1279, 1300, 1400, 1492, 1500, 1530, 1600, 1650,
  1700, 1715, 1783, 1800, 1815, 1880, 1900, 1914, 1920, 1930, 1938, 1945, 1960, 1994, 2000, 2010
- BC3000 より前は文化圏（狩猟採集民等）のポリゴンであり国家ではないため除外
- 元ファイルは 1〜2MB/断面。`mapshaper` で簡略化し 1断面 ≒ 200〜300KB に落とす。`scripts/build-data.sh` で再現可能にする（元データはリポジトリに含めず、取得＋変換を自動化）
- 使用属性: `NAME`（政体名・英語）, `SUBJECTO`（宗主）, `BORDERPRECISION`（境界精度。存在すれば透明度に反映）
- ライセンス: データが GPL-3.0 のため、本サイトのコードも GPL-3.0 で公開する

### 現代地図（下地）
- OpenStreetMap 系ラスタタイル（無料・現代の国境と都市名入り）
- 現代国境線は Natural Earth（パブリックドメイン）の 110m 国境を常時細線で重ねる（オン/オフ可）。タイルの国境はズームで消えるため別レイヤーとして持つ

### 日本語対訳 `data/names.ja.json`
- 48断面の `NAME` をユニーク抽出（実際は2548件）→ 一括翻訳 → 人手校正
- キー: 英語 `NAME`、値: 日本語名。未登録は英語のまま表示

### 「今のどこ」 `data/modern.json`
- キー: 英語 `NAME`、値: 現在の国名リスト（日本語）
- 手書き。まず主要政体（ローマ、ペルシア、漢、モンゴル等）から埋め、未登録は「（未登録）」と表示
- 版図ポリゴンと現代国境の空間交差から自動生成する案は精度が低い（にじんだ境界×粗い国境）ため採らない。ただし下書き生成には使ってよい

### 出来事 `data/events.json`
- 自前キュレーション。戦い・条約・建国・滅亡など主要100件から
- 形式: `{year, lat, lng, title_ja, summary_ja, source_url}`
- 表示: 選択断面の前後（直前の断面より後〜当該断面まで）の出来事を点で表示

## 画面（1ページ）

```
┌──────────────────────────────────────────┐
│ 現代地図タイル                            │
│   + 現代国境（細線・トグル）              │
│   + 版図ポリゴン（透明度40%、境界ぼかし）│
│   + 出来事の点                            │
│                                          │
│ クリック → 右パネル                       │
│   政体名（日本語 / 英語）                 │
│   現在の国: ○○, ○○                        │
│   宗主（あれば）                          │
├──────────────────────────────────────────┤
│ BC3000 ──●──────── 2010 [117年▸] 100年   │
└──────────────────────────────────────────┘
```

- スライダーは 48段階の離散値。ドラッグ中はラベルだけ更新し、離した時に断面をロード
- 年の入力欄に年を打って Enter（またはフォーカスを外す）と、その年に有効だった断面へ飛ぶ。
  "117" / "-500" / "紀元前500" / "BC500" / "500BC" / "前500" を受け付ける。
  断面は48しかないので打った年ちょうどの断面はまず無く、その年以前で最も新しい断面へ寄せる
  （117 → 100年の断面）。寄せた時は「→ 100年の断面を表示」と小さく出す
- 断面データは選択時に遅延ロード、ロード済みはメモリにキャッシュ
- 政体ごとの塗り色は `NAME` のハッシュから生成し、断面をまたいで同じ政体は同じ色になるようにする（変遷を目で追えるため）
- モバイルはパネルを下からのシートにする。最初はデスクトップ優先

## 技術

- 素の HTML + ES modules + MapLibre GL JS（CDN）。ビルドステップなし
- 構成
  ```
  index.html
  app.js                 エントリ。map 初期化・UI 結線
  src/eras.js            断面一覧・ロード・キャッシュ
  src/layers.js          版図/国境/出来事レイヤーの追加・差替
  src/panel.js           右パネルの描画
  src/yearinput.js       年の入力の解釈と断面への寄せ
  data/eras/*.geojson    簡略化済み48断面（生成物・リポジトリに含める）
  data/modern-borders.geojson  Natural Earth 110m
  data/names.ja.json
  data/modern.json
  data/events.json
  scripts/build-data.sh  元データ取得 + mapshaper 簡略化
  scripts/extract-names.js  NAME ユニーク抽出（対訳の下書き用）
  ```
- ホスティング: GitHub Pages（静的）

## エラー処理

- 断面ファイルのロード失敗: 前の断面を表示したままトーストで通知。再試行ボタン
- タイル取得失敗: MapLibre 標準挙動に任せる（空白タイル）
- 対訳/今のどこ が未登録: フォールバック表示（英語名 / 「未登録」）。エラーにしない

## テスト

- `src/eras.js`, `src/yearinput.js` のロジック（断面インデックス計算、年ラベル整形、年入力の解釈と寄せ）は Node の `node:test` で単体テスト
- 表示は Playwright で 3断面（bc3000 / 117相当の100 / 2010）のスクリーンショットを撮り目視確認。自動アサートは「ポリゴンが1つ以上描画されている」「クリックでパネルに NAME が出る」
- `scripts/build-data.sh` は 48ファイルが生成され各 500KB 未満であることをチェック

## 実装順

1. `build-data.sh` + 1断面表示（ここで「にじんだ境界」の見え方を決める）
2. スライダー48段階 + 遅延ロード + 年入力での移動 + 色の一貫性
3. クリック → パネル（名前・宗主・現在の国）。modern.json は主要20政体
4. 日本語対訳（抽出 → 一括翻訳 → 校正）
5. 出来事レイヤー（主要100件）
6. 現代国境トグル、モバイル対応、GitHub Pages 公開

各ステップで動くものを確認してから次に進む。
